# Powerlifter’s Companion

Powerlifter’s Companion is an Android workout planning and performance tracking app designed for powerlifters. The app helps users organize training blocks, create weekly workouts, add exercises, and track progress over time.

This project was built as part of my software development portfolio and demonstrates Android development using Kotlin, Jetpack Compose, MVVM architecture, local data persistence, and backend integration concepts.

## Technologies Used

* Kotlin
* Android Studio
* Jetpack Compose
* MVVM Architecture
* Room Database
* Supabase
* Git / GitHub

## Features

* Create and manage training blocks
* Organize workouts by week
* Add exercises to workouts
* Filter exercises when building a workout
* Delete workouts when needed
* Track performance-related training data
* Navigate between training blocks, weeks, workouts, and exercise screens
* Use a clean Android interface built with Jetpack Compose

## Project Purpose

The goal of this project is to build a practical mobile application for strength athletes who want a structured way to plan and manage their training. As a powerlifter, I wanted to create an app that reflects real training needs, including long-term programming, workout organization, and performance tracking.

## What I Built

I designed and implemented the core Android app structure, including the user interface, screen navigation, workout creation flow, exercise management, and data handling logic. The project uses MVVM architecture to separate UI behavior from application logic, making the code easier to maintain and expand.

I also worked with local data storage using Room and explored Supabase integration for authentication and remote data storage.
